This is the canonical "what's been tried" reference — kept separate from [K4_ACTIVE_RESEARCH.md](K4_ACTIVE_RESEARCH.md) (the narrative log of *why* each thing was tried, what it found, and how findings were verified) so the two can be scanned independently: this table for "has X been done," that doc for "what exactly happened and why."

This table previously lived inline inside K4_ACTIVE_RESEARCH.md's "Existing Infrastructure Status" section. Moved out 2026-09-03 after an audit found it had stopped being updated around item 15/Phase 3 — roughly two-thirds of this project's real, executed attack surface (P11-P21, all of Phases 6-8, this session's own additions) had no row in it. Every entry below was cross-checked against the code and the narrative doc before being added; nothing here is asserted without a corresponding real run.

**Convention:** ✅ Complete = implemented, executed against real K4, result recorded. ✅ Working/Verified = infrastructure component, not itself a full attack (scoring stages, search primitives). ⚠️ = a caveat worth reading before trusting the row.
