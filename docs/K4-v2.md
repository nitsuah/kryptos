# K4 makover

## Technical Design Document: Neo-Tokyo "Akira" CRT Station UI (v1)

## Overview & Goals

This document details the architecture and implementation spec for redesigning the [Kryptos Cryptanalysis Workstation](https://kryptos-k4.netlify.app/) dashboard into a retro-futuristic **Neo-Tokyo Industrial CRT Interface** (Akira Cockpit style).

The new layout converts the modern flat aesthetic into heavy mechanical panels, analog physical knobs/switches, CRT phosphor glow, and precise domain-specific telemetry grounded in the K4 cryptanalysis pipeline.

---

## Feature Flag & Migration Strategy

To ensure zero downtime and clean code maintenance, the entire redesign will sit behind an explicit runtime feature flag with a client-side layout toggle.

### 1. Flag Specification

* **Flag Key:** `ff_ui_redesign_v1_akira`
* **Default State:** `false` (Legacy UI)
* **Storage:** LocalStorage persistence key `kryptos_ui_theme_version` (`legacy` | `v1_akira`)
* **Context Provider:** Wrapped in a top-level `ThemeProvider` / `FeatureFlagContext`.

### 2. UI Toggle Controls

* **Legacy Mode:** A retro toggle switch inserted into the header top bar labeled `[ UI MODE: LEGACY / NEO-TOKYO v1 ]`.
* **Neo-Tokyo Mode:** Embedded physical rotary switch labeled `THEME SELECTOR / SYSTEM RE-Skin` located on the top panel chassis.

### 3. Cleanup Plan

* **Phase 1 (Rollout):** Feature flag enabled for beta testers and internal development.
* **Phase 2 (GA):** `ff_ui_redesign_v1_akira` set to `100% true`.
* **Phase 3 (Deprecation Cleanup):** Remove legacy css classes, obsolete layout wrappers, and the feature flag check after a 30-day grace period.

## Visual Design & Aesthetics System

* **Color Palette:**
* Chassis/Panels: Dark Brushed Slate (`#121417`), Metallic Iron (`#1C1E24`).
* Displays/Glow: High-contrast CRT Amber/Orange (`#FF9D00`), Crimson Alert (`#FF2E2E`), Phosphor Green (`#33FF66`).
* Typography Accent: Caution Yellow (`#FFCC00`).


* **Texture & Effects:**
* Scanline CSS overlay (`repeating-linear-gradient`).
* CRT screen curvature distortion via `radial-gradient` and subtle corner vignetting.
* Phosphor bloom/glow (`text-shadow`, `box-shadow` with high diffusion blur).


* **Typography:** Monospaced CRT terminal fonts (`VT323`, `Share Tech Mono`, or `Fira Code`).

### Segment Detailed Specifications

1. **Header Chassis (`#header-panel`)**
* **Title:** `SPY OPS // KRYPTOS REDESIGN V1`
* **Credits Sub-label:** `SCULPTOR JIM SANBORN COMM 1990`
* **Controls:** Master power toggle, UI version switch.


2. **K4 Ciphertext Matrix Monitor (`#cipher-matrix-crt`)**
* **Visual:** Amber CRT Nixie-style segment modules displaying the 97-character K4 Ciphertext string.
* **Functionality:** Highlights anchored plaintext segments dynamically in green/red:
* `EAST` (pos 22–25)
* `NORTHEAST` (pos 26–34)
* `BERLIN` (pos 63–68)
* `CLOCK` (pos 69–73)




3. **System Status & Vault Access (`#sys-status-panel`)**
* **Telemetry Gauges:** Analog needles for `API Signal Strength`, `CPU Load`, and `Memory Throughput`.
* **Status Indicators:** LED status lamps for `Vector Sync` and `Frontier Active` status.


4. **Global Time Sync Console (`#time-sync-panel`)**
* **Clocks:** Dual analog gauges alongside digital nixie readouts:
* `Zulu Time (UTC)`
* `Neo-Tokyo Time (JST)`
* `Berlin Clock Sync` (`00:05:00` countdown / `19:00:00` CET Frozen mark)




5. **Analysis Command & Control (`#control-surface`)**
* **Physical Controls:** Large tactile rotary dial for `ANALYSIS PRIORITY`, toggle switches for `DECODE MODE`, and mechanical sliders for `DATA FLOW SENSITIVITY`.
* **Functionality:** Directly manipulates search filters and vector queue processing in the frontend state.


6. **Sculpture Cross-Section Vault Map (`#vault-map-panel`)**
* **Visual:** Blueprint-style 3D wireframe render of the Sanborn KRYPTOS copper sculpture.
* **Interactivity:** Highlights Panel 1 (K1), Panel 2 (K2), Panel 3 (K3), and KA Segment (pos 22–75) on hover.

## Component Architecture & State Integration

```tsx
// Feature-flagged Root Wrapper Pattern
export const KryptosDashboard = () => {
  const { isNeoTokyoV1 } = useFeatureFlag('ff_ui_redesign_v1_akira');

  return (
    <main className={isNeoTokyoV1 ? "akira-crt-chassis" : "legacy-clean-layout"}>
      <TopBarHeader>
        <UiThemeToggleSwitch />
      </TopBarHeader>

      {isNeoTokyoV1 ? (
        <AkiraStationView />
      ) : (
        <LegacyDashboardView />
      )}
    </main>
  );
};

```
