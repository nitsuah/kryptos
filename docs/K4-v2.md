# K4 makeover

Breadcrumb: [Docs](INDEX.md) > K4-v2

## Technical Design Document: Neo-Tokyo "Akira" CRT Station UI (v1)

## Overview & Goals

This document details the architecture and implementation spec for redesigning
the [Kryptos Cryptanalysis Workstation](https://kryptos-k4.netlify.app/)
dashboard into a retro-futuristic **Neo-Tokyo Industrial CRT Interface**
(Akira Cockpit style).

The new layout converts the modern flat aesthetic into heavy mechanical
panels, analog physical knobs and switches, CRT phosphor glow, and precise
domain-specific telemetry grounded in the K4 cryptanalysis pipeline.

---

## Feature Flag & Migration Strategy

To ensure zero downtime and clean code maintenance, the entire redesign sits
behind an explicit runtime feature flag with a client-side layout toggle.
`useFeatureFlag()` must resolve one consistent UI mode before rendering the
main dashboard shell.

### 1. Flag Specification

- **Flag Key:** `ff_ui_redesign_v1_akira`
- **Default State:** `false` (Legacy UI)
- **Rollout Source:** The remote feature-flag provider is the source of truth
  for rollout percentage and GA state.
- **Storage:** LocalStorage persistence key `kryptos_ui_theme_version` with
  allowed values `legacy` and `v1_akira`.
- **Context Provider:** Wrapped in a top-level `ThemeProvider` /
  `FeatureFlagContext`.
- **Precedence:** `useFeatureFlag()` first evaluates
  `ff_ui_redesign_v1_akira`. If the flag resolves `false`, the UI must render
  legacy mode even when a persisted `v1_akira` value exists.
- **Fallbacks:** Missing, malformed, or unsupported persisted values must be
  treated as `legacy`. If the remote flag cannot be resolved, fall back to the
  safe legacy mode.
- **GA Behavior:** When `ff_ui_redesign_v1_akira` is `100% true`,
  `useFeatureFlag()` must always resolve `v1_akira`; the persisted value is
  ignored except for migration cleanup telemetry.

### 2. UI Toggle Controls

- **Legacy Mode:** A retro toggle switch inserted into the header top bar
  labeled `[ UI MODE: LEGACY / NEO-TOKYO v1 ]`.
- **Neo-Tokyo Mode:** Embedded physical rotary switch labeled
  `THEME SELECTOR / SYSTEM RE-Skin` located on the top panel chassis.

### 3. Cleanup Plan

- **Phase 1 (Rollout):** Feature flag enabled for beta testers and internal
  development.
- **Phase 2 (GA):** `ff_ui_redesign_v1_akira` set to `100% true` by the remote
  flag provider.
- **Phase 3 (Deprecation Cleanup):** Remove legacy CSS classes, obsolete
  layout wrappers, and the feature-flag check after a 30-day grace period.

## Visual Design & Aesthetics System

- **Color Palette:**
  - Chassis/Panels: Dark Brushed Slate (`#121417`), Metallic Iron (`#1C1E24`).
  - Displays/Glow: High-contrast CRT Amber/Orange (`#FF9D00`), Crimson Alert
    (`#FF2E2E`), Phosphor Green (`#33FF66`).
  - Typography Accent: Caution Yellow (`#FFCC00`).

- **Texture & Effects:**
  - Scanline CSS overlay (`repeating-linear-gradient`).
  - CRT screen curvature distortion via `radial-gradient` and subtle corner
    vignetting.
  - Phosphor bloom/glow (`text-shadow`, `box-shadow` with high diffusion blur).

- **Typography:** Monospaced CRT terminal fonts (`VT323`, `Share Tech Mono`,
  or `Fira Code`).

### Segment Detailed Specifications

1. **Header Chassis (`#header-panel`)**
   - **Title:** `SPY OPS // KRYPTOS REDESIGN V1`
   - **Credits Sub-label:** `SCULPTOR JIM SANBORN COMM 1990`
   - **Controls:** Master power toggle, UI version switch.

1. **K4 Ciphertext Matrix Monitor (`#cipher-matrix-crt`)**
   - **Visual:** Amber CRT Nixie-style segment modules displaying the
     97-character K4 ciphertext string.
   - **Functionality:** Highlights anchored plaintext segments dynamically in
     green/red.
   - **Highlight Convention:** Positions are zero-based character indexes and
     ranges use an inclusive start with an exclusive end.
   - **Examples:** `EAST` = `[22, 26)`, `NORTHEAST` = `[26, 35)`, `BERLIN` =
     `[63, 69)`, `CLOCK` = `[69, 74)`.

1. **System Status & Vault Access (`#sys-status-panel`)**
   - **Telemetry Gauges:**
     - `API Signal Strength` is decorative unless a backend health/latency
       field is added to `/api/status`.
     - `CPU Load` is decorative unless the backend exposes a CPU metric field.
     - `Memory Throughput` is decorative unless the backend exposes a memory
       metric field.
   - **Status Indicators:** LED status lamps for `Vector Sync` and
     `Frontier Active` status.

1. **Global Time Sync Console (`#time-sync-panel`)**
   - **Clocks:** Dual analog gauges alongside digital nixie readouts:
     - `Zulu Time (UTC)`
     - `Neo-Tokyo Time (JST)`
     - `Berlin Clock Sync` (`00:05:00` countdown / `19:00:00` CET frozen mark)

1. **Analysis Command & Control (`#control-surface`)**
   - **Physical Controls:** Large tactile rotary dial for
     `ANALYSIS PRIORITY`, toggle switches for `DECODE MODE`, and mechanical
     sliders for `DATA FLOW SENSITIVITY`.
   - **Functionality:** Directly manipulates search filters and vector queue
     processing in the frontend state.

1. **Sculpture Cross-Section Vault Map (`#vault-map-panel`)**
   - **Visual:** Blueprint-style 3D wireframe render of the Sanborn KRYPTOS
     copper sculpture.
   - **Interactivity:** Highlights Panel 1 (K1), Panel 2 (K2), Panel 3 (K3),
     and KA Segment `[22, 76)` on hover.

## Component Architecture & State Integration

```tsx
// Feature-flagged Root Wrapper Pattern
export const KryptosDashboard = () => {
  const mode = useFeatureFlag("ff_ui_redesign_v1_akira"); // "legacy" | "v1_akira"

  return (
    <main className={mode === "v1_akira" ? "akira-crt-chassis" : "legacy-clean-layout"}>
      <TopBarHeader>
        <UiThemeToggleSwitch />
      </TopBarHeader>

      {mode === "v1_akira" ? <AkiraStationView /> : <LegacyDashboardView />}
    </main>
  );
};
```

## Action Items & Milestones

1. **M1 (Scaffolding):** Set up feature-flag provider and place
   `UiThemeToggleSwitch` in top header.
1. **M2 (Styles & CRT Effects):** Build CSS utility classes for scanlines,
   phosphor glow, curved screen shadows, and metal chassis borders.
1. **M3 (Core CRT Components):** Build `K4CiphertextMatrix`, `AnalogGauge`,
   and `NixieClock` modules.
1. **M4 (Control Surface Integration):** Wire rotary dials and mechanical
   switches to existing state handlers (`searchVectors`,
   `setAnalysisPriority`).
1. **M5 (QA & Cleanup):** Verify responsiveness, test theme-toggle
   persistence, and schedule feature-flag removal.
